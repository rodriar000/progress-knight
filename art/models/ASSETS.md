# Animated hero

`hero.glb` combines Quaternius Universal Base Characters, Modular Ranger outfit and Universal Animation Library clips. The source asset is from [warptracker](https://github.com/ilrein/warptracker), which documents these assets as CC0 in its `ASSETS.md`. Original Quaternius packs: [base characters](https://quaternius.com/packs/universalbasecharacters.html), [animation library 1](https://quaternius.com/packs/universalanimationlibrary.html), [animation library 2](https://quaternius.com/packs/universalanimationlibrary2.html).
